# Política de Privacidade — Meu Gerente

Última atualização: 29 de julho de 2026

O **Meu Gerente** é uma aplicação de uso pessoal (não pública) para organizar
a produção de conteúdo de um afiliado do TikTok Shop.

## Quais dados são acessados

Ao conectar sua conta do TikTok via login (TikTok Login Kit), o aplicativo
solicita apenas informações básicas de perfil (`user.info.basic`) para
identificar o usuário logado. Nenhum dado é vendido, compartilhado ou usado
para publicidade.

## Onde os dados ficam armazenados

- Dados de conteúdo (calendário, produtos, amostras, ganchos) ficam
  armazenados localmente no navegador do usuário (localStorage), no
  dispositivo do próprio usuário.
- O token de acesso do TikTok, quando obtido, fica em memória no servidor
  local do aplicativo e é descartado ao reiniciar o servidor.

## Terceiros

Os dados não são repassados a nenhum serviço de terceiros além das chamadas
diretas necessárias à API oficial do TikTok, feitas pelo próprio usuário
autenticado.
