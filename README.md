# Meu Gerente

Sistema de organização de criação de conteúdo para afiliados do TikTok Shop.

Stack: React + Vite + Tailwind CSS.

Documentação do projeto:
- [`prd.md`](prd.md) — requisitos de produto
- [`designsystem.md`](designsystem.md) — tokens visuais
- [`CLAUDE.md`](CLAUDE.md) — diretrizes de desenvolvimento

## Comandos

```bash
npm install
npm run dev      # ambiente de desenvolvimento
npm run build    # build de produção
npm run preview  # preview do build
npm run lint      # lint (oxlint)
```
