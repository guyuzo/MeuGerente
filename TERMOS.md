# Termos de Uso — Meu Gerente

Última atualização: 29 de julho de 2026

O **Meu Gerente** é uma aplicação de uso pessoal, atualmente em fase de
desenvolvimento e testes, criada para ajudar seu único usuário a organizar a
produção de conteúdo como afiliado no TikTok Shop (calendário de postagens,
catálogo de produtos, amostras e ganchos de vídeo).

## Uso

- O aplicativo é de uso individual e não está disponível publicamente para
  terceiros.
- Os dados exibidos (métricas de GMV, comissão, vídeos postados) podem ser
  simulados (mock) enquanto a integração real com a API do TikTok não estiver
  em produção.
- Ao conectar sua conta do TikTok, você autoriza o aplicativo a ler os dados
  básicos necessários para exibir suas próprias informações dentro do painel.

## Responsabilidade

Este é um projeto pessoal em desenvolvimento, fornecido "como está", sem
garantias de disponibilidade contínua. Nenhum dado é compartilhado com
terceiros.
